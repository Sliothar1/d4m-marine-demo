# D4M Marine demo

Shareable walkthrough of the practical D4M engine on the June 2023 Connemara case.

> Nothing about the data changed. We changed the mathematics with which we look at it.

**Live demo (share this):** [https://cdn.jsdelivr.net/gh/Sliothar1/d4m-marine-demo@main/index.html](https://cdn.jsdelivr.net/gh/Sliothar1/d4m-marine-demo@main/index.html)

Pretty URL after one click in the repo: Settings → Pages → Source = GitHub Actions → save. Then [https://sliothar1.github.io/d4m-marine-demo/](https://sliothar1.github.io/d4m-marine-demo/) will work. The Actions workflow is already in the repo; `configure-pages` fails until that toggle is on.

This public page is a read-only view of answers from the private adapter [`Sliothar1/d4m-marine`](https://github.com/Sliothar1/d4m-marine). It does not run Python. It does not forecast. It is not an official Marine Institute product.

## What you can show in three minutes

| Beat | Section | Allowed sentence |
| --- | --- | --- |
| 1 | Story | Unlike facts in one array. |
| 2 | Facts | Rosmuc 320 on 29 May; Mannin 120 on 10 July. |
| 3 | Four views | The number lives on `metric/…`; everything else is presence. |
| 4 | Watch list | `y = (AAᵀ)x` is attention, not a bloom forecast. |
| 5 | Missing ≠ 0 | F19 is a gap, not SST = 0. The lie invents an edge to Mace Head. |
| 6 | Years | June 2023 is a real pulse; 2023 is not the peak year. |
| 7 | Cells × toxin | Two cell exceedances; zero DSP exceedances in the slice. |

Keys: `n` / `p` or the bottom bar. Deep links: `#risk`, `#gap`, `#years`.

## What stays in the private repo

Engine, ingest, parquet triples, tests, Codespaces, the national archive. This demo only ships the teaching numbers that already live on GitHub in `data/teaching` and `data/examples`.
